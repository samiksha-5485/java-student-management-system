# 📚 Java Student Management System

## 📌 Project Overview

A simple Java-based Student Management System for managing student records, course enrollment, and grades using SQL database.

---

## ⚙️ Technologies Used

* Java (Core Java)
* JDBC
* SQL (MySQL / PostgreSQL)

---

## ✨ Features

* Add Student
* Update Student Details
* Delete Student
* Course Enrollment
* View Courses
* View Grades

---

## 🚀 How to Run

1. Clone the repository

```bash
git clone https://github.com/samiksha-5485/java-student-management-system.git
```

2. Open project in any Java IDE (Eclipse / IntelliJ / VS Code)

3. Configure database connection in your code

4. Create required tables in database manually

5. Run the main Java file

---

## 🗄️ Database Setup

* Create database in MySQL or PostgreSQL
* Create tables manually using SQL queries
* Update database username and password in connection file
